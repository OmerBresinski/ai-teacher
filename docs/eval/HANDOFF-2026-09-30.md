## (b) Why Chalkie wins: root cause and ranked fixes

Full report: [root-cause-chalkie.md](https://github.com/OmerBresinski/ai-teacher/blob/gregwallacegb/teach-263-check-the-lesson-quality-judging-rubric-and-recent-results/docs/eval/results/2026-09-30/root-cause-chalkie.md). Three matched decks (y4 Romans, y7 particles, y8 rivers):

| | Ours (fix3) | Chalkie |
|---|---|---|
| Teaching slides | 6 | 13 |
| Check or question slides | 13 of 26 (50%) | 19% |
| Taught words on slides | ~211 | ~673 |
| Pictures carrying content / diagrams | 2 / 1 sparse | ~15 / 3 |

The main reason is lesson shape: the prompts give the slide budget to questions before any teaching gets a slide.

1. **The frame takes the teaching slides (~50% of the gap).** The planner says pupils answer on "about half the slides" and to "leave the rest for a later lesson" ([plan-lesson.ts L246–247](https://github.com/OmerBresinski/ai-teacher/blob/spike/plan-write/packages/generation/src/prompts/plan-lesson.ts#L246-L247)). The stream swap makes the starter, checks, hinge, practice and exit compulsory ([stream-lesson.ts STREAM_SWAPS](https://github.com/OmerBresinski/ai-teacher/blob/spike/plan-write/packages/generation/src/prompts/stream-lesson.ts#L37)), so a 6-slide deck keeps 1 teaching slide. **Fix:** at least half the slides after the objectives teach, and there are at least as many teaching slides as objectives. Checks fit into what is left. Delete the "later lesson" line.
2. **Slots are sized for our 43 px type (~25%).** Capacity is measured on the worst of 10 themes ([slot-contracts.ts](https://github.com/OmerBresinski/ai-teacher/blob/spike/plan-write/packages/slides/src/slot-contracts.ts), [slot-contracts.measure.ts](https://github.com/OmerBresinski/ai-teacher/blob/spike/plan-write/packages/slides/src/slot-contracts.measure.ts)). Chalkie uses 20–24 px. A photo slide holds 2 sentences. **Fix:** a teaching body size of about 30–32 px, then re-measure. **Greg's call:** the layout audit recommended keeping the big type.
3. **Diagrams die in code (~15%).** Nothing draws the `figure` form ([plan-write.ts L1164](https://github.com/OmerBresinski/ai-teacher/blob/spike/plan-write/packages/generation/src/stages/plan-write.ts#L1164)). The rivers flow diagram broke the 14-character arrow label limit ([schema.ts L149](https://github.com/OmerBresinski/ai-teacher/blob/spike/plan-write/packages/slides/src/diagrams/schema.ts#L149)) and became a stub slide ([plan-write.ts L1275](https://github.com/OmerBresinski/ai-teacher/blob/spike/plan-write/packages/generation/src/stages/plan-write.ts#L1275)). **Fix:** build the figure form or take it off the [menu](https://github.com/OmerBresinski/ai-teacher/blob/spike/plan-write/packages/generation/src/plan-write/menu.ts). Tell the writer the limits. Fall back to a teaching slide, never a stub.
4. **Pictures cost text and sit only on teaching slides (~10%).** **Fix:** give photo slides explain's text room, allow a picture on the hook or objectives slide, and drop the no-shortlist fallback that picked syringes for particles ([illustrate.ts L467](https://github.com/OmerBresinski/ai-teacher/blob/spike/plan-write/packages/generation/src/stages/illustrate.ts#L467)).

## (f) How to run and judge

Lab tools are in [docs/eval/lab](https://github.com/OmerBresinski/ai-teacher/tree/gregwallacegb/teach-263-check-the-lesson-quality-judging-rubric-and-recent-results/docs/eval/lab). Run them against a checkout of `spike/plan-write`.

**Flags (code defaults on plan-write):** `AI_LESSON_PLANNER=plan-write` on the worker; `PLAN_WRITE_MODE=stream` (the default); `PLAN_WRITE_PLANNER_MODEL=openai/gpt-6.1-sol` (the default); `LIVE_WRITING=1` on the live branch. Photos need `PEXELS_API_KEY`; without it, images are off.

**Text lessons (8 briefs):**
```
bun docs/eval/lab/fit-lab/harness/fit-drive.ts --worktree <plan-write checkout> --planner plan-write \
  --out <dir> --budget-file <spend.json> --cap <usd> --reserve 0.06 docs/eval/lab/fit-lab/briefs/*.json
```
Add `--images <photoDir>` for photos.

**Chalkie-matched lessons with images:**
```
cd docs/eval/lab/visual && WT=<plan-write checkout> PEXELS_API_KEY=... harness/gen-images-stream.sh <tag> <cap> briefs/<id>.json
```

**Budget gotcha:** the Sol stream reserves ~$0.35 against the per-lesson cap. Any `AI_LESSON_COST_CAP_USD` under that refuses it. Keep the default of 0.5 and rely on fit-drive's between-lesson guard.

**Text judging** ([README](https://github.com/OmerBresinski/ai-teacher/blob/gregwallacegb/teach-263-check-the-lesson-quality-judging-rubric-and-recent-results/docs/eval/README.md), [PROTOCOL](https://github.com/OmerBresinski/ai-teacher/blob/gregwallacegb/teach-263-check-the-lesson-quality-judging-rubric-and-recent-results/docs/eval/PROTOCOL.md)): export each deck with `bun docs/eval/tools/deck-text.ts`, blind it, then run:
- **J6** fault checklist, the main measure;
- **J5-C** head to head in both orders, the ship gate (win more than lose, no more faults);
- **J5-B** out of 5, compared only within one batch.

Judges are fresh Opus agents in a session, never lab models.

**Visual judging** ([visual README](https://github.com/OmerBresinski/ai-teacher/blob/gregwallacegb/teach-263-check-the-lesson-quality-judging-rubric-and-recent-results/docs/eval/lab/visual/README.md)): `harness/stack.sh`, then `bun harness/render.ts`, `build-packet.py`, two fresh judges on `VISUAL-JUDGE.md`, and `unblind.py`. The Chalkie reference slides are not in the repo; ask Greg for them.

**Work order:** smoke 1–2 briefs, then all 8 or 9. End each round with an independent judge: progress, rabbit hole or dead end.

## (g) Rules

UX rulings are in the [UX rulings doc](https://linear.app/missionsxyz/document/ux-rulings-268406160c7d).
- **134:** only the title is fixed; the planner picks the starter, hinge and checks per lesson. The exit ticket is a worksheet recipe, not a slide.
- **135:** every objective is taught on a slide before it is tested, at any slide count. Thin is fine; dropping one is not.
- **136:** hinge options are a word, number or short phrase. The whole hinge fits one slide on every theme and is never split.
- **137:** the title slide has a picture and no objectives. Objectives get slide 2.
- **138:** live writing: skeleton strip, layouts as forms are known, text streams in, the existing entrances are reused, and finished slides open.
- **139:** Pexels for generic photos, Commons for named things (PD/CC0/BY/BY-SA). Credits go in an info dot and the export notes, never on a slide.

Greg's standing rules:
- Quality against Chalkie beats the cost and latency caps for now. Report the caps, but do not gate on them.
- Fit first. Never shorten or move text to the notes afterwards. No splits.
- Use standard judging only.
- Log every paid run before and after.
- One PR per ticket, from master, never stacked.
- Ship decided config as code defaults.
- No AI attribution.
